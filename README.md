# Connect 4 — AI Opponent

Simple terminal-based Connect 4 game with an AI opponent.

Usage:

1. Ensure you have Python 3.8+ installed.
2. Run:

```bash
python3 main.py
```

Controls:
- Enter a column number 1-7 to drop your piece.
- Enter `q` to quit mid-game.

AI difficulty options: `easy`, `medium`, `hard`.
